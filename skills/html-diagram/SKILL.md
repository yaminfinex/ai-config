# HTML Diagram

Review the SVG diagrams used throughout `../html/references/html-effectiveness/`, focusing on the architecture-centered ones.

Also review `references/architecture-example.html` — a finished example of this skill done well (full-screen SVG stage, clickable nodes, flow chips that light up and animate request paths).

Then create an HTML file strictly for visualizing the architecture and understanding the stack: a full-screen SVG diagram, light on prose.

Build the diagram in SVG and iterate on it until every component of the stack appears on the diagram and every key flow can be traced end-to-end. Where sequences of system behavior matter, make the diagram interactive: selecting a flow animates its path through the stack.

Dark mode is required: follow `../html/references/dark-mode.md`.
