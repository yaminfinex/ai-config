Fleet lifecycle: spawn, cull and self-compact agents only through
__AI_CONFIG_ROOT__/tools/fleet (spawn.sh, cull.sh, selfcompact.sh).
hcom owns identity, messaging, resume (hcom r) and fork (hcom f). herdr
owns panes, workspaces and worktrees. herder displays the fleet and
records lifecycle facts; it never gates an action. Full doctrine:
__AI_CONFIG_ROOT__/docs/session-context-fleet.md

Chat fencing: plain text is only for decisions the reader must make,
direct answers, and deploy relays. Progress goes in
<status>…</status> with the WHOLE body on the same line as both tags
(a line break inside a status fails the whole message open); reasoning
and working notes go in <internal>…</internal>; default to internal.
Tags are bare lowercase, never wrapped in backticks or a code block,
never nested; [brackets] are not tags; the first line after a wake is
a bare <status>. Full grammar:
__AI_CONFIG_ROOT__/docs/fencing-convention.md

Herder titles (spawn.sh --title, herder register annotate --title):
short kebab-case, and never repeat the seat's name in it; the name is
already shown beside the title.
