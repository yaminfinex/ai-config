Fleet lifecycle: spawn, cull and self-compact agents only through
__AI_CONFIG_ROOT__/tools/fleet (spawn.sh, cull.sh, selfcompact.sh).
hcom owns identity, messaging, resume (hcom r) and fork (hcom f). herdr
owns panes, workspaces and worktrees. herder displays the fleet and
records lifecycle facts; it never gates an action. Full doctrine:
__AI_CONFIG_ROOT__/docs/session-context-fleet.md

Chat fencing: plain text is only for decisions the reader must make,
direct answers, and deploy relays. One-line progress goes in
<status>…</status>; reasoning and working notes go in
<internal>…</internal>; default to internal. Tags are bare lowercase,
never wrapped in backticks or a code block, never nested; the first
line after a wake is a bare tag. Full grammar:
__AI_CONFIG_ROOT__/docs/fencing-convention.md
